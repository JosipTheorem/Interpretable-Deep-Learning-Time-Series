# Sample Bead Data

This folder contains two compact raw-data samples so the bead-analysis code has a minimal runnable input.

Included samples:

- `lowrange echo 10 rad_s 1perc/individual_beads_echo1`: cluster 0 from the 1% amplitude case, with 10 full-frame bead tracks.
- `highrange echo 10 rad_s 60perc/individual_beads_echo1`: cluster 0 from the 60% amplitude case, with 10 full-frame bead tracks.

The complete raw data set is not included in git. Reuse or redistribute the sample only where the necessary data-use permission is in place.
