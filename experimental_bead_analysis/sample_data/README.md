# Sample Bead Data

This folder contains two compact experimental raw-data samples so the bead-analysis code has a minimal runnable input.

These samples are a small subset of the original experimental bead-tracking data and are included in this repository with permission for reproducibility and demonstration.

Included samples:

- `lowrange echo 10 rad_s 1perc/individual_beads_echo1`: cluster 0 from the 1% amplitude case, with 10 full-frame bead tracks.
- `highrange echo 10 rad_s 60perc/individual_beads_echo1`: cluster 0 from the 60% amplitude case, with 10 full-frame bead tracks.

The complete raw data set is not included in git. This subset is intentionally small and should be used only as the public reproducibility sample for the code in this repository.
