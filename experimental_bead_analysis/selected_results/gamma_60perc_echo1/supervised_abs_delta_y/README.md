# Supervised Mobility Figures

These figures summarize a supervised bead-mobility analysis. DCIts receives bead-motion inputs such as `raw_xy`, `rel_xy`, and `dxy` and predicts the movement magnitude:

```text
|delta raw_xy| = |raw_xy(t) - raw_xy(t-1)|.
```

The folder contains representative figures only; full generated training artifacts are intentionally not included.
